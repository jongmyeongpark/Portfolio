# 🧪 AI Lab Study

Study & practice projects from my time at the **Automotive Intelligence Laboratory, Hanyang University** (2025.06 ~ Present).
Focus areas: **state estimation** and **deep learning** for autonomous driving.

## 📁 Projects

### 1. [Optimal State Estimation Practice](./Optimal-State-Estimate-Practice)
Optimal state estimation implemented **from scratch in NumPy** — simulation → least squares → Kalman Filter → Extended Kalman Filter → Particle Filter. Applied to free-fall dynamics and 2D vehicle tracking (CV / Dead-Reckoning models).

`Python` · `NumPy` · `Matplotlib` · `SciPy`

### 2. [AUE8088 PA1 — Neural Networks from Scratch](./2026-HYU-AUE8088-PA1)
Forward propagation and **backpropagation coded by hand** (NumPy only, no autodiff) for **driving-behavior classification** from vehicle IMU data. Progresses from a toy dataset to real sensor data to a modular, PyTorch-like layer abstraction.

`Python` · `NumPy` · `Pandas` · `scikit-learn`

### 3. [AUE8088 PA2 — Active Data Curation Challenge](./2026-HYU-AUE8088-PA2)
Multi-task **scene classification** (weather / scene / time-of-day) on the BDD100K dataset. Implements CNNs (VGG, ResNet) and Vision Transformers (ViT, Swin) from scratch, tackles class imbalance & XAI (Grad-CAM), and designs a **data-curation strategy** to pick the most valuable 1,000 training images.

`Python` · `PyTorch` · `albumentations` · `captum`
